## 문제 이해
각 N명의 학생들에게 중복되지 않는 보석을 나누어 줘야할 때<br>

질투심(가장 많은 보석을 가져간 학생이 가지고 있는 보석의 개수)의 최소값 구하기<br>

ex)<br>
    학생1 보석 :  RRR<br>
    학생2 보석 :  BBBBB<br>
    학생3 보석 :  GGGG

## 풀이 아이디어
- 보석을 mid개씩 나누었을 때에 최대 몇명에게 나누어 줄 수 있는지 구하기(p)
- p와 N을 비교하여 이진 탐색
- mid개씩 보석을 나누었을 때의 질투심은 mid
