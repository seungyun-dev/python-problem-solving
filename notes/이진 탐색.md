## Binary Search / Parametric Search
둘 다 이진 탐색 알고리즘을 기본으로 한다


|  | Binary Search | Parametric Search |
|---|---|---|
| 핵심 목적 | 정렬된 데이터에서 특정 값이나 위치 찾기 | 최적화 문제 풀기 위한 값 찾기|
| 탐색 대상 | 배열의 인덱스, 값 자체 | 조건에 맞는 값 |
| 판단 기준 | arr[mid]와 비교 | mid와 비교 |
| 대표 예시 | 정렬된 리스트에서 특정 값 찾기 | 나무를 최소 m미터 얻기 위해(조건)<br> 설정해야 하는 절단기의<br> 최대 높이 값 구하기(탐색) |

## 간단정리
### Binary Search
- arr[mid]를 보고 탐색 범위를 줄임 (찾을 값을 이진 탐색)

### Parametric Search
- mid를 답의 후보로 보고, 조건을 만족하는지 확인해서 탐색 범위를 줄임 (답을 이진 탐색)
