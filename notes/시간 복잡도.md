# 시간 복잡도

## 의미
- 시간 복잡도는 입력 크기 N에 따라 알고리즘의 연산량이 어떻게 증가하는지를 나타내는 것이다(주로 최악의 경우에 대한 시간복잡도 계산)
- 대략적인 코드의 부담감을 수학적으로 표현

## 표기법
- 가장 큰 차수의 항만 남기고, 계수는 지운다.
  - 3N + 5 -> O(N)<br>
  - 7N² + 3N + 10 -> O(N<sup>2</sup>)

## 대표적인 자료구조별 연산 비용

### List

| 연산 | 시간 복잡도 | 설명 |
|---|:---:|---|
| 인덱스 접근 `lst[i]` | $O(1)$ | 원하는 위치에 바로 접근 |
| 탐색 `x in lst` | $O(N)$ | 처음부터 순차적으로 탐색 |
| `append()` | 평균 $O(1)$ | 맨 뒤에 원소 추가 |
| `pop()` | $O(1)$ | 맨 뒤 원소 제거 |
| `pop(i)` | $O(N)$ | 제거 이후 원소들을 이동 |
| `insert(i, x)` | $O(N)$ | 삽입 이후 원소들을 이동 |
| `remove(x)` | $O(N)$ | 원소를 탐색한 후 제거 |
| `sort()` | $O(N\log N)$ | 정렬 |

### Set

| 연산 | 평균 시간 복잡도 | 설명 |
|---|:---:|---|
| 탐색 `x in s` | $O(1)$ | 해시를 이용한 탐색 |
| 추가 `add()` | $O(1)$ | 원소 추가 |
| 삭제 `remove()` | $O(1)$ | 원소 삭제 |
| 교집합 `&` | $O(\min(N,M))$ | 두 집합의 원소 비교 |

### Dictionary

| 연산 | 평균 시간 복잡도 | 설명 |
|---|:---:|---|
| 조회 `d[key]` | $O(1)$ | 키를 이용한 조회 |
| 탐색 `key in d` | $O(1)$ | 키 존재 여부 확인 |
| 추가 `d[key] = value` | $O(1)$ | 키-값 추가 |
| 삭제 `del d[key]` | $O(1)$ | 키-값 삭제 |

### Deque

`collections.deque`

| 연산 | 시간 복잡도 | 설명 |
|---|:---:|---|
| `append()` | $O(1)$ | 뒤에 추가 |
| `appendleft()` | $O(1)$ | 앞에 추가 |
| `pop()` | $O(1)$ | 뒤에서 제거 |
| `popleft()` | $O(1)$ | 앞에서 제거 |
| 인덱스 접근 `d[i]` | $O(N)$ | 중간 접근은 비효율적 |

> **주의:** `list`에서 앞쪽 원소를 추가하거나 제거하면 원소들을 이동해야 하므로 $O(N)$이 걸린다.  
> 앞뒤에서 원소를 자주 추가·삭제해야 한다면 `deque`가 적합하다.
