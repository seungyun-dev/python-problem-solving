# 투 포인터 알고리즘
두 개의 포인터를 이동시키면서 탐색 범위를 효율적으로 줄여 나가는 알고리즘

## 정렬 + 양끝에서 좁혀오는 방식
- 정렬된 배열
- left와 right를 양끝에서 시작
- 조건에 따라 한쪽을 이동
- 대표적으로 두 수의 합 찾기


```
left = 0
right = n - 1

while left < right:
    s = arr[left] + arr[right]

    if s < target:
        left += 1
    elif s > target:
        right -= 1
    else:
        left += 1
        right -= 1
        ...
```
> **위 코드 해석**<br>
> 정렬된 배열에서 사용할 때 유효하며,<br>
> left를 +1 하면 s가 증가하는 방향으로 탐색하며<br>
> right를 -1 하면 s가 감소하는 방향으로 탐색한다<br>
> s == target일 때는 문제의 조건에 따라 포인터를 이동한다
> left와 right가 같아지면 반복문 종료
> n은 배열의 길이를 뜻함


## 슬라이딩 윈도우
- 연속된 구간을 대상으로 탐색
- 배열의 순서는 유지해야 함
- left와 right 둘 다 왼쪽 끝에서 시작
- right는 범위를 늘리는 방향으로, left는 범위를 좁히는 방향으로 이동함
